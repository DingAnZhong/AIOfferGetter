# Sync Helper

隐形桌面助手：屏幕上看到的 / 耳朵里听到的题目，AI 流式生成答案，提词器或拟人自动打字输出。窗口不进屏幕共享、录屏与截图，也不进任务栏和 Alt+Tab。

> ⚠️ 风险提示：本工具用于辅助笔试与面试，违反考试/面试规则的风险由使用者自担。

## 获取与激活

1. 联系客服获取安装包（仅提供 Windows 版本，macOS 支持不足暂不提供）。
2. 像普通软件一样安装并启动，首次启动会弹出激活窗口。
3. 复制激活窗口里的 16 位**机器码**发给客服，说明需要的**使用时长**。
4. 收到 `AIOH1.` 开头的密钥后粘贴进激活窗口，**粘贴后自动激活**，直接进入主界面。

一把密钥只属于一台电脑、有到期日；到期或更换电脑后重新找客服换新密钥即可，原有设置不丢。

## 功能一览

- **隐形 overlay**：对屏幕共享 / 录屏 / 截图不可见，窗口名伪装为 "Settings"，可调透明度、变色龙自动融入桌面
- **笔试通道**：热键框选题目 → 本地离线 OCR → AI 流式答案
- **面试通道**：系统声音自动转文字 → 直发 AI（仅收系统声音，不收麦克风）
- **提词器**：自动滚动可调速，滚轮手动滚动，无复制按钮（答题平台会检测粘贴）
- **auto-typer**：拟人节奏逐字键入答案，绕过粘贴检测，Esc 随时中断
- **启动授权**：密钥绑定机器 + 有效期，防冒用与跨机器重放

详细操作见[用户手册](用户手册.md)。
